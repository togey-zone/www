# TOGEY Zone

Public foyer for **TOGEY LIMITED** / **桃吉有限公司**.

This repository hosts the lightweight Jekyll site behind `zone.togey.com`. The
current goal is to turn the old temporary facade into a credible main portal that
can explain the company, the domain matrix, and the staged rebuild roadmap.

## Rebuild direction

1. **Phase 1 — Credible doorway**: tighten the homepage copy, hierarchy, contact
   path, and domain matrix so visitors can quickly understand TOGEY.
2. **Phase 2 — Content system**: add concise pages for company profile, product
   lines, operating regions, and collaboration notes.
3. **Phase 3 — Product surfaces**: move serious projects into dedicated domains
   or subdomains, with the main portal acting as the verified index.

## Local build

This site uses GitHub Pages-compatible Jekyll settings.

```bash
bundle exec jekyll build
```
